# Template Guide

## セクション増減の考え方

### 画面が増える場合

以下のファイルで `## [画面名]` セクションを追加します。

- `S-Layout.md`
- `FuncSpec.md`
- `Event.md`
- `FuncDetail.md`
- `Check.md`

例:

```markdown
## [第一画面]

## [第二画面: 詳細]

## [第三画面: 確認ダイアログ]
```

### ボタンが増える場合

以下を追加します。

- `S-Layout.md` のフッター表にボタン行を追加
- `FuncSpec.md` に `### 「[ボタン名]」ボタン` を追加
- `Event.md` にイベント行を追加
- `FuncDetail.md` にボタン押下処理を追加
- 必要に応じて `Check.md` にチェック仕様を追加

### SQLやDBアクセスが増える場合

以下を追加します。

- `Relation.md` に `## [移送名]` セクションを追加
- `FuncDetail.md` の該当処理に `参照Sheet: Relation` を記載
- CRUD対象が増える場合は `Outline_B.md` の CRUD表に行を追加

### チェックが増える場合

以下を追加します。

- `Check.md` にチェック行を追加
- `FuncSpec.md` に入力チェック、論理チェック、排他チェックとして概要を追加
- `FuncDetail.md` に実装レベルのチェック処理を追加

### 固有情報を入れないテンプレート化のルール

- 業務名、画面名、テーブル名、カラム名、ボタン名は `{{...}}` または `[ ... ]` に置換します。
- SQLは構造だけを残し、テーブル名・カラム名は `[TABLE_NAME]`、`[COLUMN_NAME]` に置換します。
- メッセージ文は `[メッセージ文]` として、業務固有の状態名を残しません。
- サンプルが必要な場合でも、実在業務に見えない一般的な名称を使います。
