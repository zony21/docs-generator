# Docs Generator 機能設計書

## 1. 画面構成

初期実装は1画面だけとする。

```text
+------------------------------------------------------------+
| Docs Generator                                             |
+------------------------------------------------------------+
| 1. 機能共通情報                                            |
|    システム名、機能ID、機能名、Rev、作成者など            |
+------------------------------------------------------------+
| 2. 作成する設計書                                          |
|    [基本のみ] [全選択] [全解除]                            |
|    [x] Hist [x] Outline_A ... [ ] S-Layout                 |
+------------------------------------------------------------+
| 3. 設計内容                                                |
|    ▼ Hist                                                  |
|    ▼ Outline_A                                             |
|    ▼ FuncSpec                                              |
|    ▼ 選択済みの設計書                                     |
+------------------------------------------------------------+
| 4. Markdownプレビュー                                     |
|    ファイル選択 + 生成Markdownソース                       |
+------------------------------------------------------------+
| [入力クリア] [ZIP出力]                                     |
+------------------------------------------------------------+
```

画面遷移、ルーター、ホーム画面、プロジェクト一覧は設けない。

## 2. 機能共通情報

| 項目 | 部品 | 必須 | 動作 |
| --- | --- | --- | --- |
| システム名 | input | 必須 | 前回値を初期候補にする |
| モジュール名 | input | 任意 | 前回値を初期候補にする |
| モジュールID | input | 任意 | なし |
| 機能ID | input | 必須 | 出力フォルダ名に使用 |
| 機能名 | input | 必須 | 出力フォルダ名とREADMEに使用 |
| 機能概要 | textarea | 必須 | READMEに使用 |
| 文書番号 | input | 任意 | 共通メタデータに使用 |
| 作成日 | date | 必須 | 当日を初期値にする |
| Rev | input | 必須 | `0.1`を初期値にする |
| 作成者 | input | 必須 | 前回値を初期候補にする |
| 備考 | textarea | 任意 | READMEに使用 |

共通情報は各設計書へ自動反映し、設計書ごとに再入力させない。

## 3. 設計書選択

### 3.1 初期選択

次の6設計書を選択済みで開始する。

- Hist
- Outline_A
- Outline_B
- FuncSpec
- FuncDetail
- Relation

### 3.2 追加選択

次は未選択で開始する。

- S-Layout
- R-Layout
- Event
- Check
- Others
- Footnote

### 3.3 一括操作

- 基本のみ
- 全選択
- 全解除

設計書の自動推奨や文章解析は行わない。

## 4. 設計内容入力

選択済み設計書だけを折りたたみセクションとして表示する。

タブや設計書別画面は作らない。

### 4.1 共通操作

- セクションを開閉する。
- 表の行を追加する。
- 表の行を削除する。
- 直前の行を複製する。
- 行を上または下へ移動する。
- No.を自動採番する。

ドラッグ&ドロップ並び替え、Undo、複雑なキーボードショートカットは実装しない。

## 5. 設計書別入力

### 5.1 Hist

- 作成・更新日
- 作成者
- Rev
- 対象設計書・対象領域
- 変更内容
- 承認日
- 承認者
- 追加注記

共通情報から初回履歴行を作成できる。

### 5.2 Outline_A

- 目的
- 対象範囲・対象ユーザー・対象処理
- 概要フロー
- 前提条件
- 後続条件

概要フローは1行1ステップで入力する。

### 5.3 Outline_B

- 処理方式・分類
- CRUD・操作区分
- 関連テーブル・マスタ・インターフェース
- 制約・備考

### 5.4 FuncSpec

複数のアクションを追加できる。

- 画面・機能単位
- トリガー・タイミング
- 目的
- 主な手順
- 正常時の動作
- エラー・中断時の動作

### 5.5 FuncDetail

複数の処理単位を追加できる。

- 処理名
- 関数・メソッド名
- 関数種別
- 概要
- 通常処理
- 例外処理
- 終了処理
- 関連設計書

`try`、`catch`、`finally`は入力がある場合だけ出力する。

### 5.6 Relation

複数のデータ関係を追加できる。

- Transfer Source
- 転送元条件
- Transfer Destination
- 転送先条件
- SQL
- 備考

Transfer SourceとTransfer Destinationは分離して出力する。

### 5.7 S-Layout

- 画面領域
- コントロール一覧
- コントロール属性
- 表示・編集ルール
- 画面画像

画像仕様は`07_IMAGE_ASSET_SPEC.md`に従う。

### 5.8 R-Layout

- レイアウトブロック
- 出力項目
- 列定義
- 出力時の注意事項
- 帳票・出力画像

画像仕様は`07_IMAGE_ASSET_SPEC.md`に従う。

### 5.9 Event

- イベント名
- トリガー
- 対象機能・処理
- 備考

### 5.10 Check

- 画面名
- チェック名
- タイミング
- チェック項目
- 種別
- 詳細
- メッセージID
- メッセージ引数

### 5.11 Others

- 共通定数
- 選択肢
- ファンクションキー・補助マッピング
- 運用注記

### 5.12 Footnote

- 用語
- 説明
- 略称・コード
- 定義
- 補足注記

## 6. Markdownプレビュー

- 生成対象ファイルの一覧をselectで切り替える。
- 選択ファイルのMarkdownソースを`pre`要素で表示する。
- 入力変更後にプレビューを更新する。
- 初期実装ではHTMLレンダリング表示を行わない。
- 画像は選択中のFileオブジェクトを使用して別途サムネイル表示する。

## 7. 自動保存

- 文字入力と表データをLocal Storageへ保存する。
- 保存スロットは1件だけとする。
- 画面起動時に保存済み入力を復元する。
- 「入力クリア」で保存データも削除する。
- 画像ファイル本体は保存しない。

## 8. ZIP出力

ZIP出力ボタン押下時に次を行う。

1. 必須項目を検証する。
2. 選択済み設計書を生成する。
3. README索引を生成する。
4. 画像参照と画像ファイルを検証する。
5. ZIPを作成する。
6. `<機能ID>_<機能名>.zip`としてダウンロードする。

## 9. エラー表示

初期実装で出力を停止するエラーは次とする。

- システム名未入力
- 機能ID未入力
- 機能名未入力
- 作成者未入力
- Rev未入力
- 設計書が1件も選択されていない
- 未置換テンプレートトークンが残っている
- 対応外画像
- 画像参照先がZIPへ格納されていない

## 10. 操作削減の受け入れ条件

- 1画面で入力から出力まで完結する。
- 共通情報を一度だけ入力すればよい。
- 基本6設計書が選択済みで開始する。
- 日付とRevが初期入力される。
- 表行を複製できる。
- 文字入力を再読み込み後に復元できる。
- 不要な設計書入力欄を表示しない。
