# Updated Workflow Acceptance Checklist

- Sheet summary is read-only until Edit is pressed.
- Edited summary values are included in generated Markdown.
- Common settings, table settings, and selected sheets are separate pages.
- Tabs and Previous/Next buttons move between pages.
- Registered tables/resources can be selected in Outline_B and Relation.
- Input labels start with defaults and can be changed.
- Optional input fields can be hidden and restored.
- Hiding a field does not delete its data.
- Preview can switch between rendered Markdown and source code.
